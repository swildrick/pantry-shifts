# Tokens

The design tokens live in `src/theme.ts`, and every value on this page is read from it. Components read them through the MUI theme: palette paths such as `'primary.main'`, spacing units in `sx` (`p: 2.5`), and Typography variants. Never write a raw hex or pixel value in a component; see `src/design-system.md` for the full rules.

The same tokens are Figma variables in the [Pantry Shifts Figma file](https://www.figma.com/design/ZJMiZk0z3IHq6Q7LWP4q4g/Pantry-Shifts). The last column of each table gives the Figma variable name.
